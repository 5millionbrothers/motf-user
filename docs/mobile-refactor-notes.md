# 모바일 개선 1차 적용 메모

## 이번에 바꾼 것

- PC 화면은 그대로 두고, 760px 이하에서만 새 모바일 탐색 구조를 사용합니다.
- 상단은 브랜드·현재 화면명·채팅으로 단순화했습니다.
- 홈 중단에는 MOriginal·커뮤니티·레크레이션·문의 채팅을 배치했습니다.
- 하단에는 홈·숙소·내 MT·장보기·마이 5개 핵심 탭을 배치했습니다.
- iPhone 노치와 하단 홈 인디케이터를 위한 safe-area 여백을 추가했습니다.
- 작은 아이콘 버튼의 모바일 터치 영역을 44px로 확장했습니다.

## 코드 정리 방식

- 모바일 전용 UI를 `mobile-shell.css`와 `mobile-shell.js`로 분리했습니다.
- 기존 `styles.css`와 `app.js`를 대규모로 건드리지 않아 기능 회귀 위험을 줄였습니다.
- 현재 경로별 `index.html` 31개는 완전히 동일합니다.
- 루트 `index.html`을 원본으로 수정한 뒤 `tools/sync-route-pages.sh`를 실행하면 모든 경로 복사본이 동기화됩니다.

## 다음 리팩터링 권장 순서

1. 실제 운영 핵심 시나리오에 대한 자동 스모크 테스트 추가
2. `app.js`에서 라우팅, 숙소, 장보기, 결제, 커뮤니티를 모듈별로 분리
3. CSS를 토큰, 공통 컴포넌트, 화면별 스타일로 분리
4. 경로별 HTML 복사본 제거 가능성 검증

기능 테스트가 없는 상태에서 5,000줄짜리 파일을 한 번에 분할하면 눈에 안 보이는 동작이 깨질 수 있으므로, 먼저 테스트 안전망을 만든 뒤 단계적으로 분리하는 편이 안전합니다.
