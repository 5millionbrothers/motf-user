## 적용 순서

최종 전달본 `motf-local-design-v2-logo-20261103`은 V2 전체 변경과 새 로고를 모두 포함합니다. 이전 V2 ZIP 대신 이 파일을 사용합니다. 로고 교체로 인한 추가 SQL은 없으며 기존 86번 SQL은 동일합니다.
제공받은 152×111 SVG를 그대로 `assets/motf-symbol.svg`에 보관하고, 화면별 비율·여백만 조절합니다. 핀 아이콘/영문 워드마크 조합은 심볼 하나로 바꿉니다. PNG/ICO/Apple 아이콘은 같은 벡터에서 생성하고, 로딩은 동일한 로고 형태를 마스크로 그립니다. 현재 정적 운영 화면 외의 차기 Next 화면은 로고 이미지·메타데이터·아이콘만 동기화하며 기능은 수정하지 않습니다.

1. 기존 85번까지 적용된 운영 DB와 백업을 확인합니다. 예전 SQL 전체를 다시 실행하지 않습니다.
2. `motf-database/supabase/86_community_gatherings_and_mt_records.sql`을 Supabase SQL Editor에서 실행합니다. 기존 프로젝트·게시글을 삭제하거나 결제 테이블을 변경하지 않습니다.
3. 이용자 저장소의 V2 파일을 같은 상대경로에 덮어씁니다. 30개 직접 접속용 `index.html`도 함께 올립니다.
4. 사장님 저장소의 `public/owner/` 변경 파일을 함께 올립니다. 현재 운영 기준은 이 정적 디렉터리이며 차기 `src/` 화면에 중복 구현하지 않습니다.
5. 기존 NICEPAY·KCP·Naver·Supabase 환경변수는 변경하지 않습니다. 새 환경변수나 패키지 설치는 필요하지 않습니다.
6. 배포 후 아래 점검을 진행합니다. 이 패키지는 운영 배포나 운영 DB 실행을 자동으로 수행하지 않습니다.

## 데이터 연결

### 홈과 배너

- 홈: 실제 승인 카탈로그, 공개 커뮤니티 글, 운영자 콘텐츠만 표시합니다.
- 풀배너 첫 장은 내 MT 만들기입니다. 나머지는 기존 `homepage_cards`와 공개 MOriginal 행사에서 가져옵니다.
- `메인 배너`에서 등록·수정·정렬·노출 기간·연결 주소를 관리합니다. 기존 카드뉴스와 프로모션도 보존하고 배너 데이터로 사용합니다.
- 홈 계산기는 시안의 전체 기능(인원·날짜·예산 단위 조절·색상별 분배·기타 비용)을 유지합니다. 예시 분배는 실제 숙소 가격이나 확정 견적이 아닙니다.
- 새 MT로 이어갈 때 인원·날짜·전체 예산·직접 입력한 기타 비용만 넘깁니다. 예시 숙소·장보기 비용은 저장하지 않습니다. 기존 MT 선택 시 기존 예산을 덮어쓰지 않습니다.

### 커뮤니티

- 상단: 추천 레크레이션, 같이 가요. 현장 게시판: 나눔장터, 대결신청, 현장 정보, 다른 MT 기록(2×2).
- 기존 게시판·댓글·첨부·신고·운영자 모니터링 기능은 운영 어댑터를 그대로 사용합니다.
- 같이 가요: 로그인 후 모집 글 등록·수정·마감. 글과 일정·모집 조건을 하나의 DB 함수에서 원자적으로 저장합니다. 댓글은 기존 커뮤니티 댓글을 사용합니다.
- 다른 MT 기록: 완료한 MT의 수정 권한자가 공개 항목을 선택하고 명시적으로 동의해야 공개됩니다. 인원·예산·지역·품목 검색 및 유사 인원 정렬을 지원합니다.
- 공개 데이터에는 별도 공개 기록 ID와 승인된 항목만 포함합니다. 비공개 MT ID·사용자 ID·연락처·채팅·공지·결제 내역은 공개 함수에서 반환하지 않습니다.
- 숙소명·장보기 품목·레크 이름은 각각 선택 동의합니다. 공개 메모에는 이용자가 공개하려는 내용만 입력합니다. 동의 철회·운영자 숨김·MT 재진행 시 공개 목록에서 즉시 제외됩니다.
- 추천 주문량 도구는 장보기로 이동합니다.

## 검증과 한계

- 나이스 결제/환불/API 자동 테스트 64개.
- 격리 PostgreSQL(PGlite)에서 86번 SQL 반복 적용, 기본 권한 자동 부여 환경, 작성 권한·개인정보 투영·동의 철회·운영자 숨김·원자적 저장 테스트 7개.
- 데스크톱/모바일 9개 너비 × 공개 화면 9개 조합. 홈 원본과 글꼴·크기·굵기·행간·색·그림자·여백의 대표 요소 20개 비교.
- 인증된 동작은 모의 로그인/DB를 사용해 내 MT 이어가기·공개/철회·모집 등록/수정/마감·기존 나이스 호출을 검증합니다. 실제 결제나 운영 DB 쓰기는 수행하지 않습니다.
- 등록된 도메인을 사용하는 로컬 응답 환경에서 실제 Naver SDK와 지도 재진입을 검증합니다. localhost는 운영 지도 키 허용 도메인이 아니므로 로컬 미리보기에서는 지도가 제한될 수 있습니다.
- 배포 후 실제 계정으로 로그인·예약·장바구니·테스트 결제/취소·운영자 배너 수정·새 커뮤니티 저장을 다시 확인해야 합니다. 자동 테스트가 실제 운영 전체 검증을 대신하지는 않습니다.
